## Hex Map Editor

This is a project that seeks to be a one stop shop for the Rose Gold Railroad campaign. This includes a dyamic hex map of exploration, a town webpage to show the beloved town NPCs, and will soon track player XP, duty and leisure. 


### Changeable Bits

Currently, you'll need to tweak a bunch of magic numbers to create your own grids of hexes, but if you want your own map, simply delete the current json file down to an empty [] and go to admin view to edit the map from there. If you want to add more assets, add the image to /images, and add it to AssetList.json following the format there.
